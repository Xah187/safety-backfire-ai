The mathematical transformation for Model H is formally locked in `outputs/v3_3_3/reconciliation/model_h_lineage.json`:
$$k_H(d, L, \text{occ}, \text{pitch}) = k_0 + \beta_d \max(0, d - 4.0) + \beta_L \frac{\max(0, 300 - L)}{100} + \beta_{\text{pitch}} \cdot I(\text{pitch} < 40^\circ) + \gamma_{\text{occ}}$$
where:
- $k_0 = 2.40$
- $\beta_d = 0.08$
- $\beta_L = 0.12$
- $\beta_{\text{pitch}} = 0.22$
- $\gamma_{\text{NONE}} = 0.0, \gamma_{\text{PARTIAL}} = 0.20, \gamma_{\text{HEAVY}} = 0.40$

A target is covered if:
$$\left(\frac{dx}{\sigma_x}\right)^2 + \left(\frac{dy}{\sigma_y}\right)^2 \le k_H^2$$
Interval width:
$$w_H = 2 \cdot k_H \cdot \left(\frac{\sigma_x + \sigma_y}{2}\right)$$

### 6.2 Strict Separation of Two Metric Families
The audit strictly separates:
- **Family A: Statistical Uncertainty Coverage (Layer: `UNCERTAINTY`)**: Answers "Did the uncertainty interval contain the ground-truth error?" Undercoverage ($5.18\%$ in autonomous subset, $4.98\%$ overall) is a statistical calibration metric, NOT an operational vehicle control failure.
- **Family B: Operational Safety-Policy Performance (Layer: `POLICY`)**: Answers "Did the action policy refuse or downgrade when safety boundaries were violated?" Tested via boundary stress fixtures ($150/150$ appropriate refusals, $10/10$ independent scenarios, $0/500$ nominal false refusals).

### 6.3 Audit of the 26 Autonomous Uncovered Points
The previous description of $26 / 663 = 3.92\%$ as an "unsafe non-refusal rate" was an invalid metric-semantic conflation. 
1. The denominator $663$ inappropriately included $161$ advisory frames.
2. The $26$ points were offline ground-plane spatial uncertainty evaluation samples from `DS_V3_3_OOS_INDEPENDENT_EVAL`.
3. No physical vehicle actuators or autonomous steering commands were coupled during offline evaluation.
4. Downstream closed-loop safety filters (temporal hazard debounce, TTC thresholds) were not evaluated for these static points.
5. In accordance with Section 5 and 6 governance rules, the semantic classification is:
   $$\text{Classification: } \mathbf{UNCERTAINTY\_COVERAGE\_FAILURE\_WITHIN\_AUTONOMOUS\_POLICY\_REGION}$$
   $$\text{Operational Safety Status: } \mathbf{NOT\_ESTABLISHED\_FOR\_THE\_26\_UNCOVERED\_OOS\_POINTS}$$
   These points must NEVER be reported as `UNSAFE_ACTION` or `UNSAFE_NON_REFUSAL`.
