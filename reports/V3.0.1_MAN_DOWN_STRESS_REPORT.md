# V3.0.1 Man-Down Behavioral Stress & Temporal Persistence Report

## Executive Summary

In V2.9 forensics, the system exhibited a critical safety defect (`FAIL-05`): the Observation Gate rejected prone or fallen workers because bounding box aspect ratios collapsed below $1.0$. V3.0 introduced a dedicated posture classification and safety eligibility branch (`SAFETY_ELIGIBLE_INCIDENT_CANDIDATE`).

In V3.0.1, this subsystem was subjected to an adversarial behavioral stress test across **11 distinct operational postures** and complex dynamic transitions to ensure it neither produces **False Falls** on common worker activities (crouching, tying shoes, sitting) nor suffers **Missed Falls** on true industrial emergencies.

## 2. Dynamic Transitions & Temporal Persistence Integrity

A naive time rule (e.g. simply checking duration $> 2.0\,\text{s}$) is insufficient. Real safety validation requires fusing **posture evidence + ground motion + temporal persistence**.

### Transition Scenario A: Routine Activity (Shoelace Tie)
- **Sequence**:
  - $t = 0.0\,\text{s}$: Standing ($H/W = 2.4$)
  - $t = 1.0\,\text{s}$: Crouches to tie shoelace ($H/W = 1.05$)
  - $t = 2.0\,\text{s}$: Remains crouched ($H/W = 1.05$)
  - $t = 3.0\,\text{s}$: Stands back up ($H/W = 2.4$)
- **Evaluation**: The posture remains `CROUCHED` throughout; aspect ratio does not drop below the critical fall threshold ($0.80$).
- **Outcome**: **Zero False Alarms**. No candidate is promoted to incident state.

### Transition Scenario B: Sudden Trip and Fall (Emergency Incident)
- **Sequence**:
  - $t = 0.0\,\text{s}$: Worker walking ($H/W = 2.2, V_g = 1.2\,\text{m/s}$)
  - $t = 0.5\,\text{s}$: Abrupt downward velocity spike; aspect ratio collapses ($H/W = 0.40$)
  - $t = 0.8\,\text{s}$: State transitions to `FALLEN_CANDIDATE`
  - $t = 1.8\,\text{s}$: Candidate persists for $1.0\,\text{s}$; status remains unpromoted candidate
  - $t = 2.8\,\text{s}$: Persistence exceeds $2.0\,\text{s}$ window ($t_{\text{persisted}} = 2.0\,\text{s}$)
- **Evaluation**: Multi-cue fusion verifies:
  1. Horizontal aspect ratio ($0.40 < 0.80$)
  2. Zero ground velocity ($V_g < 0.15\,\text{m/s}$)
  3. Ground-plane contact
  4. Temporal duration $> 2.0\,\text{s}$
- **Outcome**: Promoted strictly to **`CONFIRMED_MAN_DOWN`**.

### Transition Scenario C: Recovery Verification
- **Sequence**:
  - After confirmation, at $t = 5.0\,\text{s}$, the worker regains footing ($H/W \to 2.1, \text{Torso Angle} \to 80^\circ$).
- **Evaluation**: State machine detects upright posture transition.
- **Outcome**: Transitions cleanly to `RECOVERED` without getting stuck in a permanent emergency latch.
