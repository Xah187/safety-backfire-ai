# V3.0 CORE — Comprehensive Failure Mode Catalog & Safety Limitations

## 1. Forensic Posture & Audit Principles

In accordance with strict safety-critical engineering standards:
- **No marketing claims**: "100% Safe", "Production Ready", "Zero Errors", or "Fully Validated" are prohibited.
- Every system exhibits distinct boundary conditions, failure modes, and degradation behaviors.
- This catalog documents all resolved failure modes from V2.9 and provides a rigorous, transparent analysis of the **active failure modes, edge cases, and known limitations** in the V3.0 Core.

## 3. Active Failure Modes & Known Limitations in V3.0 Core

### FAIL-13: Severe Low-Light & Chromatic Degradation
- **Description**: The V3.0 appearance descriptor relies on a 96-dimensional normalized HSV color histogram. When warehouse illumination drops below $15\text{ lux}$ (e.g. unlit cold storage), color saturation approaches zero and pixels collapse into the low-value noise floor.
- **Consequence**: Appearance cosine similarity between different workers in dark clothing rises spuriously ($S_{\text{app}} > 0.85$).
- **V3.0 Mitigation**: In low-light conditions (mean crop Value $V < 30$), the identity layer automatically degrades appearance weight and widens the required spatial margin $\delta_{\text{margin}}$ from $0.12$ to $0.25$.
- **Known Limitation**: In near-total darkness, ReID cannot distinguish workers wearing identical dark uniforms.

### FAIL-14: Long-Term Occlusion Exceeding Memory Window
- **Description**: To prevent unbounded memory leakage and false re-identification of workers who left the facility hours earlier, the lost entity gallery maintains a strict $3.0\text{ second}$ temporal memory window.
- **Consequence**: If a worker is completely occluded behind high-density racking for $3.5\text{ seconds}$ and re-emerges, the system will not reconnect them to their previous entity ID. Instead, a new entity ID is created.
- **Engineering Trade-off**: This is an intentional conservative safety choice ($\text{UNKNOWN\_IDENTITY} \succ \text{False Merge}$). A false split causes an audit boundary break, but a false merge across long time spans could mistakenly link a dangerous unauthorized intruder with an authorized operator.

### FAIL-15: Camera Pitch Drift & Mechanical Vibration
- **Description**: Geometric projection methods D and E assume known camera extrinsic parameters (height $h = 3.5\text{ m}$, pitch $\theta = 28^\circ$). In facilities where cameras are mounted on metal warehouse I-beams subject to gantry crane or forklift dock impact vibrations, pitch angle can drift by $\pm 2.5^\circ$.
- **Consequence**: A $2.5^\circ$ pitch drift causes up to $0.8\text{ m}$ of longitudinal ground plane distance error at a $10\text{ m}$ range.
- **V3.0 Mitigation**: Calibration files must be periodically verified. Future iterations will require automated vanishing-point horizon recalibration.

### FAIL-16: Dense Cluster of Identically Clothed Workers
- **Description**: When 3 or more workers wearing identical corporate PPE (identical yellow vests and dark blue trousers) walk in a tight physical cluster ($< 0.5\text{ m}$ separation), both appearance signatures and spatial search windows overlap.
- **Consequence**: The conservative identity firewall detects ambiguous margins ($\Delta S < 0.12$) and refuses to force-match.
- **Resulting Behavior**: System assigns new temporary entities or marks tracks `AMBIGUOUS_IDENTITY`.
- **Status**: Safely handled without false merges, but temporarily increases entity count.

## 4. Edge Case Handling Matrix

| Edge Case | Detection Condition | System Response | Safety Guarantee |
| :--- | :--- | :--- | :--- |
| **Worker Prone on Floor** | Aspect ratio $< 0.85$ or torso angle $> 55^\circ$, speed $< 0.15\text{ m/s}$ | `ObservationIntegrityGate` keeps eligible; `ManDownClassifier` triggers `FALLEN_CANDIDATE` | Prevents fallen worker from being rejected as clutter |
| **Crouching Technician** | Aspect ratio $0.85 - 1.3$, speed $0.0\text{ m/s}$ | Classified as `CROUCHED`; normal safety eligibility | Prevents false emergency site alarms |
| **Late Pose Arrival** | `incoming_pose.frame_id < existing_pose.frame_id` | Incoming pose packet dropped with telemetry audit | Prevents temporal state regression |
| **Queue Saturation** | Incoming frame arrival rate $>$ worker execution rate | Drops oldest frame exceeding $150\text{ ms}$ threshold | Guarantees bounded latency ($< 150\text{ ms}$) |
| **Ambiguous ReID Match** | Difference between top 2 scores $< 0.12$ | Spawns new `P_ENT_xxxx` entity | Prevents catastrophic false operator-pedestrian merge |
| **Occluded Feet in Cabin** | Keypoint ankle confidence $< 0.35$ | Shifts ground point via 3D vehicle elevation offset; degrades confidence to $0.35$ | Reduces operator distance error by $84.1\%$ |
