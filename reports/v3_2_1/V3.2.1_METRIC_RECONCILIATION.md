## 3. Detailed Forensic Corrections

### 3.1 Critical Issue #4: Pooled vs. Macro Hazard Metric Resolution
In V3.2, the master table reported:
- Precision: $0.9537$
- Recall: $0.9371$  
These numbers were derived as $\frac{268}{281} = 0.9537$ and $\frac{268}{286} = 0.9371$.
- **Audit Correction:** Aggregating all true positives over all trials across classes is a **Pooled / Micro Average**, not a Macro Average. A true Macro Average weights each of the 12 hazard classes equally regardless of trial count.
- In V3.2.1, both metrics are officially published:
  - **Micro / Pooled Metrics:** Precision $= 0.9537$, Recall $= 0.9371$, F1 $= 0.9453$.
  - **Macro Metrics:** Precision $= 0.9480$, Recall $= 0.9288$, F1 $= 0.9380$.

### 3.2 Critical Issue #6: Tracking ID Switch Rate Denominator Resolution
In V3.2, the metric $2.03$ was labeled as "ID switches per 1,000 frames".
- **Audit Correction:** The denominator used in the code was $3,450$, which is the total count of **entity-frame instances**, not physical frames ($1,672$).
- In V3.2.1, both denominators are explicitly reported:
  - **Rate per 1,000 Entity-Frame Instances:** $\frac{7}{3450} \times 1000 = \mathbf{2.03}$.
  - **Rate per 1,000 Physical Video Frames:** $\frac{7}{1672} \times 1000 = \mathbf{4.19}$.
