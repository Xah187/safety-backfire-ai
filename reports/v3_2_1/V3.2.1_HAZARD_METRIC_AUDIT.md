## 3. Mathematical Derivations: Micro vs. Macro

### 3.1 Pooled / Micro Metrics
Aggregates raw incident counts across all hazard types into a single global pool:
$$\text{Micro Precision} = \frac{\sum TP_i}{\sum TP_i + \sum FP_i} = \frac{268}{268 + 13} = \frac{268}{281} = \mathbf{0.9537} \; (95.37\%)$$
$$\text{Micro Recall} = \frac{\sum TP_i}{\sum TP_i + \sum FN_i} = \frac{268}{268 + 18} = \frac{268}{286} = \mathbf{0.9371} \; (93.71\%)$$
$$\text{Micro F1} = \frac{2 \cdot 0.9537 \cdot 0.9371}{0.9537 + 0.9371} = \mathbf{0.9453} \; (94.53\%)$$

### 3.2 Unweighted Macro Metrics
Computes the arithmetic mean of individual class scores, treating each hazard category with equal weight:
$$\text{Macro Precision} = \frac{1}{12} \sum_{i=1}^{12} P_i = \frac{11.376}{12} = \mathbf{0.9480} \; (94.80\%)$$
$$\text{Macro Recall} = \frac{1}{12} \sum_{i=1}^{12} R_i = \frac{11.146}{12} = \mathbf{0.9288} \; (92.88\%)$$
$$\text{Macro F1} = \frac{1}{12} \sum_{i=1}^{12} F1_i = \frac{11.256}{12} = \mathbf{0.9380} \; (93.80\%)$$
