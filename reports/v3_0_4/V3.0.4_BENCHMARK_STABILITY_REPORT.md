# V3.0.4 — Benchmark Stability & Performance Audit Report

## 1. Executive Summary & Measurement Boundaries

To prevent historical benchmarking errors (such as conflating isolated compute duration with end-to-end queue latency), V3.0.4 enforces four distinct measurement boundaries across all performance reports:
1. **`compute_decision_latency_ms`**: Isolated algorithm execution duration (geometry projection + covariance uncertainty + risk policy).
2. **`arrival_to_decision_ms`**: Ingestion queue residency + worker dispatch + compute duration.
3. **`source_capture_to_decision_ms`**: Camera optical sensor hardware capture timestamp to decision publication.
4. **`pose_source_age_at_decision_ms`**: Temporal freshness of pose estimation keypoints relative to decision wall clock.

## 2. Four-Regime Performance Audit

### 2.1 Regime A: Burst Overflow Stress (Backpressure Invariant)
- **Injection Rate**: $2000\,\text{FPS}$ simulated network flood ($100$ frames in $50\,\text{ms}$).
- **Queue Capacity**: Bounded at $N_{\text{max}} = 5$.
- **Overflow Dropped Frames**: $95$ frames.
- **Burst Drop Rate**: **$95.0\%$**.
- **Final Queue Depth**: $5$ frames (Zero queue growth).
- **Verdict**: **PASS**. Bounded frame queue strictly guarantees deterministic memory upper bounds under network bursts.

### 2.2 Regime B: Sustained Replay ($25\,\text{FPS}$, Paced $40\,\text{ms}$)
- **Evaluated Stream Frames**: $250$ frames ($10$ seconds of continuous processing).
