# V3.1 — Entity Taxonomy & State Representation Model

## 1. Overview & Architectural Role

The **V3.1 Entity Representation Model** establishes a comprehensive, strongly-typed classification for all physical warehouse objects, human actors, structures, machinery, and spatial fixtures.

Prior to V3.1, the system represented objects as raw bounding boxes with rudimentary labels (`"person"`, `"forklift"`). In V3.1, entities are modeled as stateful, spatiotemporally grounded objects inheriting from `EntityBase`.

## 3. Stateful Attribute Enums

Entities possess dynamic physical and behavioral states that evolve over time:

### 3.1 PostureState (Human Kinematic Posture)
| State | Geometric Criterion | Safety Consequence |
| :--- | :--- | :--- |
| `UPRIGHT_WALKING` | BBox $AR < 0.85$, $v > 0.4\,\text{m/s}$, torso vertical | Normal operational transit |
| `UPRIGHT_STANDING` | BBox $AR < 0.85$, $v \le 0.4\,\text{m/s}$, torso vertical | Stationary worker in workstation or lane |
| `BENDING` | Torso angle $30^\circ \le \theta < 60^\circ$ from vertical | Ergonomic strain; reduced visual field |
| `CROUCHING` | $0.85 \le AR < 1.30$, knees bent $>60^\circ$ | High risk of blind-spot occlusion by pallets |
| `PRONE` | $AR \ge 1.30$, horizontal torso, face down | **Man-Down Candidate**: Imminent medical/crush alarm |
| `SUPINE` | $AR \ge 1.30$, horizontal torso, face up | **Man-Down Candidate**: Imminent medical/crush alarm |
| `FALLING` | Vertical velocity $v_z < -1.5\,\text{m/s}^2$ | Dynamic fall detection; immediate alert dispatch |
| `SEATED` | Coupled to vehicle cabin coordinates | Operator cabin suppression activated |
| `UNKNOWN` | Keypoint visibility $< 0.40$ | Treated with maximum clearance buffer |

### 3.2 StructuralState (Physical Integrity of Structures & Loads)
| State | Structural Symptom | Safety Consequence |
| :--- | :--- | :--- |
| `INTACT` | Vertical deflection $< 0.5^\circ$, load centered | Nominal capacity |
| `DEFLECTED` | Elastic column deflection $0.5^\circ \le \theta < 2.0^\circ$ | Advisory maintenance inspection |
| `OVERLOADED` | Beam sag exceeding $L/200$ | Warning: reduce bay load immediately |
| `DEFORMED` | Permanent plastic column bend after vehicle impact | **CRITICAL**: Evacuate bay; collapse hazard |
| `UNSTABLE` | Pallet stack lean $> 4.0^\circ$ or broken pallet base | **CRITICAL**: Immediate exclusion zone |
| `COLLAPSING` | Dynamic structural failure in progress | Emergency evacuation sirens |

### 3.3 OperationalState (Machinery & Vehicle Activity)
- `IDLE`: Powered off or parked; zero kinematic hazard.
- `OPERATIONAL`: Active movement or rotating machinery; standard safety envelopes enforced.
- `MAINTENANCE`: Service mode; requires Lockout/Tagout (LOTO) verification.
- `ESTOP_ACTIVATED`: Emergency stop engaged.
- `UNKNOWN`: Default fail-closed state; treated as operational until verified.

## 4. 3D Spatial Grounding & Geometric Boundaries

Every entity maintains ground-plane coordinates $\mathbf{p} = (X_w, Y_w)$, height $Z_w$, speed $v$, heading $\theta$, and a 2D ground support polygon:

$$\mathcal{P}_{\text{ground}} = \{ (x_1, y_1), (x_2, y_2), \dots, (x_n, y_n) \}$$

### Key Geometric Rules:
1. **Ground Support Projection:** Zone occupancy and clearance are evaluated on $\mathcal{P}_{\text{ground}}$, **never on unprojected 2D bounding boxes**. This guarantees that upper-body perspective bleed does not trigger false zone violations (**FAIL-32**).
2. **Elevation Shift:** Vehicle cabin centers ($Z = 1.40\,\text{m}$) and person heads ($Z = 1.70\,\text{m}$) are projected to ground plane using exact closed-form homography ray intersection, eliminating elevation parallax (**FAIL-10**, **FAIL-24**).
3. **Spatial Covariance:** Every position is bound to a $2 \times 2$ covariance matrix $\mathbf{\Sigma}_{2\text{D}}$ representing empirical localization uncertainty.
