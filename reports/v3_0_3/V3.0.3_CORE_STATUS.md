## 3. Open Failures & Identified Defects

### FAIL-23: Non-Linear Euclidean Distance Positive Bias & Empirical Coverage Under-Coverage
- **Severity**: HIGH
- **Status**: **`OPEN DEFECT`**
- **Discovered In**: V3.0.3 Independent Empirical Coverage Suite.
- **Measured Finding**:
  - Nominal target coverage: $95.0\%$.
  - Empirical coverage achieved: **$89.0\%$** ($[81.4\%, 93.7\%]$ Wilson CI), failing the $\ge 90\%$ statistical acceptance threshold.
  - Positive metric residual bias: **$+0.1269\,\text{m}$**.
  - Skewness: **$+0.5676$** (Non-Gaussian tail).
- **Physical Root Cause**:
  Euclidean distance $d = \|\Delta \mathbf{x}\|$ is a non-linear convex norm. Coordinate noise in orthogonal axes expands the vector magnitude, systematically biasing measured distance upward. Symmetric first-order Gaussian assumption underestimates proximity risk.
- **Remediation Plan for V3.0.4**:
  Implement second-order bias correction ($\mathbb{E}[d] \approx d + \frac{1}{2d}\operatorname{Tr}(\boldsymbol{\Sigma}_\perp)$) or non-parametric conformal quantile calibration.
