## 3. Detailed Subsystem Evaluations

### 3.1 Geometry Subsystem
- **V3.0.2 Baseline**:
  The test script `test_geometry_integrity_adversarial.py` calculated `ideal_shift = (fy * ho * math.cos(pitch)) / d` and compared it to `engine.compute_parameterized_elevation_shift_px()`. Because both used the exact same arithmetic expression, residual error was trivially $0.000\,\text{px}$.
- **V3.0.3 Improved**:
  The test script `test_geometry_ground_truth_independent.py` deployed independent physical ground markers with total station laser coordinates. Error is now measured in physical meters ($0.58\,\text{m}$ lateral MAE, $4.40\,\text{m}$ longitudinal MAE). Furthermore, the exact projective equation proved that the first-order approximation breaks down at steep angles ($45^\circ$), producing up to $1112\,\text{px}$ error.

### 3.2 Uncertainty & Risk Subsystem
- **V3.0.2 Baseline**:
  Distance uncertainty was computed via an isotropic heuristic and intervals were labeled "95%" without empirical validation.
- **V3.0.3 Improved**:
  Full 2D Jacobian covariance propagation was implemented. Testing against 100 independent pairs proved that nominal $95\%$ intervals achieve only $89.0\%$ coverage due to non-linear Euclidean norm expansion ($+0.127\,\text{m}$ positive bias). Rather than adjusting thresholds to force a pass, this defect was transparently cataloged as `FAIL-23`.

### 3.3 Temporal Safety Subsystem
- **V3.0.2 Baseline**:
  Pose freshness was evaluated using wall-clock elapsed time since pose worker compute completed.
- **V3.0.3 Improved**:
  Pose freshness is derived strictly from camera sensor exposure PTS. In the Critical Source-Frame Switch test, an operator who was seated in Frame 100 and dismounted in Frame 102 was correctly protected when the delayed Frame 100 pose arrived at Frame 103: suppression authority was revoked (`STALE_POSE_SOURCE_AGE_120.0MS`), maintaining immediate proximity protection.

### 3.4 Benchmark Methodology
- **V3.0.2 Baseline**:
  Claimed an "$81\%$ latency reduction" by comparing V3.0.1 video residency ($115.68\,\text{ms}$) to V3.0.2 paced compute duration ($22.00\,\text{ms}$).
- **V3.0.3 Improved**:
  The direct comparison was formally retracted. Benchmark integrity was rebuilt into 4 distinct regimes:
  - Burst Overflow Drop Rate: $95.0\%$ under 1000 FPS flood (Regime A).
  - Sustained Compute Latency P95: $20.82\,\text{ms}$ (Regime B).
  - Sustained End-to-End Source-to-Decision P95: $20.89\,\text{ms}$ (Regime B).
  - Real Video Decoding P95: $4.48\,\text{ms}$ (Regime C).
  - Memory / Thread Leak Drift: $+0.00\,\text{MB}$, $+0$ threads (Regime D).

## 4. Retracted Claims Summary

1. **Retracted Claim 1**: "Parameterized perspective elevation offset achieves 0.000px error (Mathematically Exact)."
   - *Correction*: The formula is a first-order linear approximation exhibiting up to $1112.55\,\text{px}$ truncation error outside its operational envelope.
2. **Retracted Claim 2**: "Combined distance uncertainty is ±0.83m via covariance propagation."
   - *Correction*: $0.83\,\text{m}$ was the unrounded pedestrian-only uncertainty ($0.825\,\text{m}$). True combined RSS is $0.776\,\text{m}$ (or $0.849\,\text{m}$).
3. **Retracted Claim 3**: "81% latency improvement from V3.0.1 (115.68ms) to V3.0.2 (22.00ms)."
   - *Correction*: Direct comparison retracted due to unequal measurement boundaries (queue residency vs isolated compute duration).
