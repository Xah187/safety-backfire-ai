# V3.0.5 Adversarial Failure Injection & Safe Degradation Report

## 1. Executive Summary

In safety-critical robotics and computer vision, inputs can become corrupt due to sensor dropouts, numerical singularities, partial occlusion, or communication faults. A production safety system must **fail closed**—it must never crash, throw unhandled runtime exceptions, or silently produce false confident safety outputs when corrupt data enters the perception pipeline.

Phase 7 subjected the Geometry and Uncertainty Risk Engines to malicious and boundary fault injections:
1. Floating-point anomalies: `NaN`, `+Inf`, `-Inf`.
2. Physically invalid metric values: negative distance ($d = -2.5\,\text{m}$).
3. Degenerate covariances: zero matrix, singular matrix (rank 0 / non-positive definite).
4. Zero uncertainty ($\sigma = 0.0\,\text{m}$) and zero evidence quality ($\text{evidence} = 0.0$).

**Results:** Zero unhandled exceptions. All corrupt states degraded safely into `HIGH_PRIORITY_CANDIDATE`, `CONFIRMED_DANGER` (fail-closed for proximity breach), or `SAFE` (for infinite distance), preserving system uptime and physical safety.

## 3. Safe Degradation Architecture

1. **Covariance Regularization:**
   In `GeometryEngineV3.compute_distance_with_uncertainty`:
   ```python
   sigma_d = float(math.sqrt(max(1e-6, var_radial)))
   ```
   Singular or zero-rank covariance matrices are regularized via a floor of $10^{-6}\,\text{m}^2$, preventing division by zero or NaN propagation during Rice factor scaling.
2. **Distance Boundary Clamping:**
   In `UncertaintyAwareRiskEngine.evaluate`:
   ```python
   d_nom = max(0.0, float(nominal_distance_m))
   u_1sigma = max(0.05, float(distance_uncertainty_m))
   ```
   Negative distances are clamped to $0.0\,\text{m}$ (maximum proximity threat), ensuring that perception corruptions default to fail-closed alerts rather than silent passes.
3. **Temporal Skew & Age Guards:**
   In `PoseContract.evaluate_suppression_authority`:
   Stale or out-of-order timestamps immediately trigger `SKEW_EXCEEDED` or `STALE_POSE_SOURCE_AGE`, stripping suppression authority without raising runtime errors.
